== 1. Introduction and Goals

=== 1.1 Purpose

The repository provides a Python-based toolchain to:

* statically analyze Java source trees,
* generate Byteman instrumentation rules,
* launch Java processes with Byteman `-javaagent` integration (Linux/Bash wrapper),
* monitor runtime trace logs (`BTM_EVT` lines),
* detect and classify race-suspect overlaps heuristically,
* execute repeated scenario-based stress runs and aggregate outcomes.

This scope is implemented primarily in `byteman_static/` and exercised by tests in `tests/` plus WSL scripts in `verification/scripts/`.

=== 1.4 Main Use Cases

* Analyze a Java source root and generate `Byteman.log` + `generated-rules.btm`.
* Generate a launcher script that injects Byteman agent and runtime properties.
* Monitor runtime logs continuously and emit suspect lines + JSONL report.
* Execute scenario-driven stress iterations and inspect aggregate outcome levels:
  `BENIGN`, `SUSPICIOUS`, `REPEATED_SUSPICIOUS`, `HIGH_CONFIDENCE_SUSPICIOUS`.

=== 1.5 Success Criteria

* CLI commands return expected outputs and error codes for valid/invalid inputs (`byteman_static/cli.py`).
* Artifacts are written in expected directories and formats (`generator.py`, `stress_runner.py`).
* Runtime parser handles key-value and JSON lines (`runtime_parser.py`, tests).
* Monitor resists malformed/truncated/duplicate lines without crashing (`runtime_monitor.py`, tests).
* Stress run produces traceable per-iteration and aggregate JSON outputs.
